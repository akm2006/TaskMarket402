# Demo Script

## Opening

TaskMarket402 is a Mission Budget WorkGraph. It turns one MetaMask permission into an auditable budget for autonomous agent teams.

## Flow

1. Create a Wallet / Token Risk Report mission.
2. Set mission budget to 3 USDC and max per-agent spend to 0.50 USDC.
3. Approve one scoped MetaMask mission budget.
4. Show Manager Agent splitting work into Contract Scanner, Wallet Behavior, and Market Context agents.
5. Show Contract Scanner requiring x402 payment.
6. Show at least one payment relayed or tracked through 1Shot.
7. Show specialist output returning.
8. Show Venice verification.
9. Show final Venice synthesis.
10. Show WorkGraph audit trail and one blocked payment case.

## Key Line

This is not an agent marketplace or trading bot. It is a bounded, auditable funding layer for autonomous agent work.
