# TaskMarket402 Product Brief

## One-Liner

TaskMarket402 turns one MetaMask permission into an auditable mission budget for autonomous agent teams.

## Locked Concept

A user creates a mission, approves one scoped budget, and a Manager Agent splits that budget into sub-budgets for specialist agents. Agents are paid through x402, at least one ERC-7710/x402 payment is relayed by 1Shot, outputs are verified by Venice AI, and the WorkGraph shows every permission, payment, output, and result.

## MVP Mission

Wallet / Token Risk Report.

The user enters a target wallet or token address, a 3 USDC mission budget, a mission duration, and a maximum per-agent spend. The Manager Agent creates subtasks for:

- Contract Scanner Agent.
- Wallet Behavior Agent.
- Market Context Agent.

## Why This Is Distinct

TaskMarket402 is not a generic marketplace, trading bot, x402 wrapper, or chatbot. The differentiator is that agent work becomes fundable, bounded, and auditable through a mission budget. The WorkGraph proves how authority and money move through the agent team.

## Product Principle

Never make the product marketplace-first. It is mission-budget-first and WorkGraph-first.
